# Faisal Ahmed — Animated Developer & Data Science Portfolio

An ultra-modern, high-performance interactive portfolio built for **Faisal Ahmed** (Final-Year CSE Student at AIUB | Data Science, Machine Learning & Software Engineering).

## ✨ Key Animated & Interactive Features
- **60fps Neural Network Particle Canvas (`#neural-canvas`)**: Interactive particle nodes & synapses that react to mouse movement.
- **Futuristic Boot Preloader**: Smooth loading progress animation before revealing the Hero section.
- **3D Tilt Hero Profile Card & Dynamic Typewriter**: Interactive 3D perspective card with floating orbital tech badges and live terminal snippet.
- **Spotlight Glassmorphism Bento Grid**: Mouse-tracked radial spotlight glow across all cards.
- **Interactive Skills Filter & Animated Mastery Bars**: Category tabs (`Programming`, `Web & Frameworks`, `Databases`, `Tools, Graphics & AI`) with scroll-triggered progress bars.
- **5 Featured Projects with Case Study Modals & Video Demo**:
  1. **Cargo Flow – From Warehouse to Sea** (`C++`, `OpenGL` + embedded Google Drive video demonstration)
  2. **Recipe Sharing Platform** (`PHP`, `JavaScript`, `MySQL`, `XAMPP`)
  3. **Library & Inventory Management System** (`C#`, `.NET`, `SQL Server`, `OOP2`)
  4. **Restaurant Order & Table Management API** (`ASP.NET Core`, `EF Core Code-First`, `N-Tier Architecture`)
  5. **Perfume Decant Management App** (`Python`)
- **Embedded Interactive CV Viewer & Direct PDF Download**: Preview or download `Faisal Ahmed_CV.pdf` in 1 click.
- **Dark Cyber-Tech Mode & Clean Light Mode**: Instant theme switching with `localStorage` persistence.

## 🚀 How to Run Locally
1. Simply double-click [`index.html`](./index.html) to open it in any browser, **or**
2. Run a local server:
   ```bash
   python -m http.server 8080
   ```
   Then visit `http://localhost:8080`.
